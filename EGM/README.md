# EGM artifacts

The Elephant-Goldfish Model's working folder for this repository: `concepts_brief.md` from
`/egm:egm-brainstorm`, `design_draft.md` from `/egm:egm-draft`, and the review reports from
`/egm:egm-review`. `CLAUDE.md` names it with the line `EGM artifact directory: EGM`.

Everything here except this file is ignored by git. Brainstorms and drafts can name unreleased
realms and other things that stay out of this public repository (`CLAUDE.md`); a design that is
ready to keep is copied out, screened, and committed as a design doc instead.

The plugin itself (skills, Goldfish personas, document standards) lives in Claude Code's plugin
cache, not here; `.claude/settings.json` enables it for the repository.
