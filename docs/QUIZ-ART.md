# Which owl are you: the pictures to paint (OP-326)

Every answer in the quiz has a picture slot. Until it is painted, the game draws a dashed box with
the size on it ("96 × 96"), so the artist knows how big to make each piece.

- **Size:** 96 × 96 px, square, transparent background (PNG or WebP). The game shows it smaller on
  a phone (64 px at least), so keep the shape bold and readable at that size.
- **Style:** the park's hand-painted look; one clear thing per picture, owl life only (a burrow, a
  hollow, the moon), no words and no emoji.
- **Names:** save each as `<art key>.png`, for example `dusk.png`. The key is the first column below.
- **Count:** 85 pictures, on 28 cards.

The words come from `packages/shared/src/whichOwlBank.ts`; when a card changes there, change this
list too.
